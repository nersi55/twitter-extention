# Instagram Auto Action Extension

افزونه کروم برای اتوماسیون عملیات در اینستاگرام (لایک، فالو، کامنت)

## قابلیت‌ها

- ❤️ **لایک خودکار پست‌ها**
- ➕ **فالو کردن کاربران**
- 💬 **ارسال کامنت خودکار**
- 📜 **اسکرول خودکار صفحه**
- ⏸️ **توقف و ادامه عملیات**
- 🗑️ **پاک کردن صف دستورات**
- ⚙️ **تنظیم تاخیر بین عملیات**

## نصب

1. باز کردن کروم و رفتن به آدرس `chrome://extensions/`
2. فعال کردن **Developer mode** (حالت توسعه‌دهنده)
3. کلیک روی **Load unpacked**
4. انتخاب پوشه `instagram-auto-extension`

## استفاده

1. وارد سایت اینستاگرام شوید (`https://www.instagram.com`)
2. روی آیکون افزونه کلیک کنید
3. نوع عملیات مورد نظر را انتخاب کنید
4. برای کامنت، متن مورد نظر را وارد کنید
5. روی دکمه **شروع عملیات** کلیک کنید

## تنظیمات

- **تاخیر بین عملیات**: زمان انتظار بین هر عملیات (برای جلوگیری از بلاک شدن)
- **اسکرول خودکار**: فعال/غیرفعال کردن اسکرول خودکار پس از هر عملیات

## ساختار فایل‌ها

```
instagram-auto-extension/
├── manifest.json       # فایل پیکربندی افزونه
├── background.js       # اسکریپت پس‌زمینه (مدیریت صف)
├── content.js          # اسکریپت محتوا (تعامل با صفحه)
├── popup.html          # رابط کاربری
├── popup.js            # منطق رابط کاربری
└── README.md           # این فایل
```

## نکات مهم

⚠️ **هشدار**: استفاده بیش از حد از این افزونه ممکن است منجر به محدود شدن یا مسدود شدن حساب شما شود.

- تاخیر مناسب بین عملیات تنظیم کنید (حداقل 3 ثانیه)
- از ارسال کامنت‌های تکراری خودداری کنید
- در مدت زمان کوتاه تعداد زیادی عملیات انجام ندهید

## تکنولوژی‌ها

- Manifest V3
- Chrome Extensions API
- Vanilla JavaScript
